#  Adecco HR Analytics Dashboard – Excel Project

##  Project Overview

Designed and developed a fully interactive **HR Analytics Dashboard** in Microsoft Excel to analyze employee workforce data and uncover key HR insights for better decision-making.

This project focuses on:

* Employee Attrition Analysis
* Workforce Demographics
* Employee Satisfaction Trends
* Department-wise Insights
* HR KPI Tracking

The dashboard was redesigned with a modern and professional UI to improve readability, user experience, and business presentation.

---

##  Key Insights

* Total Employees: **1,470**
*  Active Employees: **1,233**
*  Attrition Rate: **16.1%**
*  Average Satisfaction Score: **2.73 / 4**
*  Average Employee Age: **36.9 Years**
